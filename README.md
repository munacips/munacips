## 🚀 What I'm Building

### 🤖 My Personal Assistant
A personal AI agent that plans, acts, observes and adjusts in a loop. It can call tools, chat via Telegram or a custom interface, read and write local files, run code and database queries, and even suggest new tools for itself. Uses **Tesseract** for OCR and **Scriberr** for voice-to-text.

### 🏭 Agent Factory
A meta-agent that turns a business's process descriptions into per-department workflows (marketing, sales, development and so on), then generates the **LangGraph / LangChain** agents to run them, with human approval at every step. Built with **Python + uv**.

### 💻 Cross-Platform Shell
A shell that runs on both Linux and Windows and understands both worlds, so `cls` and `clear` do the same thing everywhere.
